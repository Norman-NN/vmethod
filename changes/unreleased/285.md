kind: breaking

Workers run in their own checkout through OpenCode, and GitHub access comes only from `GH_CONFIG_DIR`. Adopting projects must:

- clone the repository a second time for workers and set `workerCheckout` (or `VMETHOD_WORKER_CHECKOUT`);
- gitignore `.claude/`, with each checkout's `.claude/settings.local.json` setting its identity (`VMETHOD_ROLE`, `GH_CONFIG_DIR`, git author and SSH command);
- log each identity into its gh config directory, since `GH_TOKEN` is no longer read.

`worker start` now creates the task worktree with OpenCode's worktree API, runs `npm ci` and writes `.vmethod/.env` naming the task, so worker verbs need no `VMETHOD_TASK_PR` prefix; branch-based context inference is gone. Cleanup removes worktrees through OpenCode.

Removed, each now invalid in configuration:

- the `claude -p` backend and `kind: claude` (Claude models run through OpenCode's `claude-code` provider);
- `credentials.githubToken`, `workerGithubToken` and `workerPassword`;
- `workerUser`/`workerGroup` two-user access;
- the `start-task` verb.
